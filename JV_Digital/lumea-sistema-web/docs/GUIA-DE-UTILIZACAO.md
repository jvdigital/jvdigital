# Guia de utilização do sistema

## Entrar na gestão interna

Abra `admin.html` e use a palavra-passe inicial `admin123`.

## Gerir marcações

1. Abra o separador `Marcações`.
2. Altere o estado para `pendente`, `confirmada` ou `cancelada`.
3. Apague registos quando já não forem necessários.
4. Exporte JSON regularmente para backup.

## Gerir produtos e fotografias

1. Abra `Galeria/produtos`.
2. Edite títulos PT/EN, descrições, preço e categoria.
3. Pode colar uma URL de imagem ou carregar uma imagem local.
4. Clique em `Guardar alterações`.

## Gerir serviços

1. Abra `Serviços`.
2. Edite nome, descrição, duração e preço.
3. Estes serviços aparecem automaticamente no formulário de marcação.

## Exportar/importar dados

Use `Dados locais` para criar uma cópia JSON. Para mover o site para outro computador, importe esse JSON no novo navegador.

## Alterar idioma no site público

Use o seletor PT/EN no topo. A escolha fica guardada no navegador.
