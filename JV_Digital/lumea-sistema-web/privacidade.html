Política de Privacidade

Este site usa dados locais no navegador para gerir marcações e preferências. As marcações submetidas ficam guardadas no dispositivo onde o site é usado, salvo exportação ou integração posterior com uma base de dados.

O Google Analytics só é carregado após consentimento no banner de cookies. Pode recusar a qualquer momento limpando os dados do navegador.

Os botões de WhatsApp abrem uma conversa externa, sujeita às políticas da Meta/WhatsApp.

Para exercer direitos de acesso, rectificação ou eliminação, contacte: ola@lumea.pt.
